# The Reader's Eye

**About:** an eye engraved from young adult novel quotes, drawn in a single web page.

Open `index.html` in a browser to see it.

## About the quotes

Every line in the eye is a short excerpt from a published young adult novel: 24 quotes from 15 books. The page credits each one with its book and author, in the caption as you read the eye and in the list "Every quote in this eye", and [CREDITS.md](CREDITS.md) lists every book.

The quotes are used as the material of a typographic artwork, each short and credited. They are not covered by this repository's code licence; each belongs to its author and publisher. No quote has been removed so far. If you are an author or publisher and want one removed, open an issue on this repository and it will be taken down.
